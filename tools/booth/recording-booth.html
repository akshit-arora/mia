Recording booth

0/0 Mic level

Before you start. Type the language folder name (for example en or hi). Files in the zip are named <folder>/<key>.take<N>.<ext>; unzip into the project's recordings/ folder, then run npm run audio:pack.

Microphone access. Browsers only allow the microphone on https pages or on localhost (Chrome also allows file:// after you grant permission; Safari and Firefox may not). If recording does not start, serve this folder locally, for example cd tools/booth && python3 -m http.server 8765, then open http://localhost:8765/recording-booth.html.

Tips. Phone 15 to 20 cm away, same distance every time, half a second of silence before and after. Up to 3 takes per line; choose "Keep this take" for the best one. Takes stay in this browser if you refresh. Nothing is uploaded anywhere.
